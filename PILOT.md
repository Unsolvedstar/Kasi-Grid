# Pilot plan: getting real traction in a weekend

Goal: 20 people in one suburb, 1 spaza owner, 1 ward councillor or community group admin.

1. Pick a suburb you know. Set it as the default area before sharing.
2. Message the local WhatsApp group: "Download Kasi Grid (link). Report outages so we know what is really happening."
3. Ask the spaza owner to try the Business tab and give one quote about what it saves.
4. Share the Today update with the WhatsApp button once a day.
5. Record numbers from `/api/stats` (anonymous, last 7 days) daily: neighbours, reports, offers, "back on" votes.
6. Put the final numbers and one quote on slide 9 of the deck.

Report only real numbers. Items marked Sample and the demo seed scripts are excluded from or separate from `/api/stats` when run on a throwaway database.
